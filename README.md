# RentKaro — Premium Coffee & Sand Theme

This version is rebuilt to match the supplied premium reference:
- Dark espresso / warm sand palette
- Premium automotive hero image
- Six vehicle categories only: All Vehicles, Sedan, Hatchback, SUV, Bike, Scooter
- Compact responsive cards and tables
- Homepage order: Hero → Search → Categories → Featured Vehicles → Why Choose Us → Customer Reviews → Popular Locations → How It Works → Offer → Newsletter → Footer
- All secondary pages use the same design system.

## Run in VS Code
1. Extract the ZIP.
2. Open the `RentKaro` folder in VS Code.
3. Open `index.html`.
4. Use Live Server for the best experience.

The project remains plain HTML/CSS/JavaScript, so no build process is required.
